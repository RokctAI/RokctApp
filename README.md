# RokctApp

RokctApp is the ROKCT-branded manager: a Flutter shell for small business owners (free local-only POS, see `docs/ROKCT_POS.md`), built on the RokctAI fleet pattern: composed from fleet SDKs at build time via The-Rokct-Protocol composer.

## Status

The repo was wiped of its legacy Foodyman-fork code. Scope decided (Ray, 2026-10-26): this repo is the ROKCT-branded manager (free POS). `composer.json` and `.rokct/config/app_type` define the shell; the Flutter project is generated by compose and is not committed yet.

## Layout

- `composer/` — composer variant templates (including `supacharge.json`) and their README
- `docs/` — architecture docs (core SDK shared database, offline-first implementation guide, SDK indirect communication, original SDK implementation plan, handoff notes)
- `.rokct/` — protocol bootstrap (`compose.py`), project memory, decision log, and workspace sync scripts
