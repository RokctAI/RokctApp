# RokctApp

RokctApp is the ROKCT-branded manager: a Flutter shell for small business owners (free local-only app, see `docs/ROKCT_APP.md`), built on the RokctAI fleet pattern: composed from fleet SDKs at build time via The-Rokct-Protocol composer.

## Status

The repo was wiped of its legacy Foodyman-fork code. Scope decided (Ray, 2026-10-26): this repo is the ROKCT-branded manager (free app). `composer.json` and `.rokct/config/app_type` define the shell; the Flutter project is generated by compose and is not committed yet.

## Layout

- `composer.json` — the SDK list for this app
- `docs/ROKCT_APP.md` — how the free local tier works, build flag, store identity and to-do list
- `.rokct/` — protocol bootstrap (`compose.py`), project memory, decision log, and workspace sync scripts
